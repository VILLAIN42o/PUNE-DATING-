PUNE DATING — STARTER DEMO

1. Unzip this folder.
2. Open index.html in Chrome/Edge.
3. Enter a name and age 18+.
4. Try the Like, Match, Chat and Report demo.

IMPORTANT:
This is a front-end demo only. It does NOT provide real online registration,
real accounts, a server, database, payments, or real-time chat.

For a real public dating website, you will need secure backend authentication,
database/storage, moderation, privacy controls, age/identity verification,
report/block tools, HTTPS, and hosting.
